# Сервис новостей (news-app)

REST-сервис новостей на **Java 8 + RESTEasy + Undertow**. Один Maven-проект, который
развивался от ЛР1 к ЛР7: REST API, DTO, бизнес-объекты и фасад, декоратор,
контроллеры, репозитории, DAO.

## Что делает проект

Сервис обслуживает три роли: читатель, журналист и администратор.

* **Читатель** - лента новостей, поиск по ключевым словам, фильтры по региону и
  периоду, категории, полный текст новости, комментарии, избранное.
* **Журналист** - создание, редактирование и удаление новостей, теги, медиа,
  публикация, снятие с публикации, архив.
* **Администратор** - пользователи, роли, блокировка, модерация комментариев.

Доступ к функциям - через REST API (`/reader`, `/creator`, `/admin`) и веб-интерфейс.

## Реализованные паттерны

| Паттерн | Где | Назначение |
|---------|-----|------------|
| Singleton | `SingletonAPI`, `FacadeController`, `Database` | один экземпляр на приложение |
| DTO | `view/api/dto` | передача данных между клиентом и сервисом |
| Facade | `FacadeController` | единая точка входа в бизнес-логику |
| MVC | `view` / `controller` / `model` | разделение представления, логики и данных |
| Decorator | `NewsDecorator`, `PositiveNewsDecorator` | фильтрация негативных новостей без изменения контроллера |
| Repository | `controller/repository` | доступ к данным поверх бизнес-объектов |
| DAO | `model/dao` | универсальный доступ к SQLite и MongoDB |

## Технологии и данные

* Java 8, Maven, RESTEasy, Undertow, Jackson, HTML/CSS/JS без фреймворков.
* **SQLite** - файл `news.db` создаётся автоматически и хранит пользователей,
  роли, категории, теги, новости, комментарии и избранное.
* **MongoDB** - опционально, хранит полный текст новостей (`newsdb.news_contents`).
  Если сервер не запущен, текст временно хранится в памяти, и приложение работает.

## Запуск

```bash
mvn clean package
java -jar target/news-app.jar
```

* Интерфейс: **http://localhost:8080/**
* Тестер API: **http://localhost:8080/static/tester.html**

MongoDB поднимается отдельно: служба Windows, `mongod --dbpath ...` или
`docker run -p 27017:27017 mongo:7`. Без неё сервис тоже запускается.
